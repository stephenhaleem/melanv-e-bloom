# Architecture rules
- Keep the founder story at the existing `/about` URL and the brand mission at `/why-we-exist`; separate pages distinguish personal narrative from purpose without breaking existing story links.
- Use presentation-local story copy for this redesign rather than legacy About content keys; stale saved copy must not reintroduce unrelated founder claims.
- Keep style and texture browsing in the Shop page with validated search state; one shopping destination reduces navigation clutter while keeping views shareable.
- Import video asset pointers and preserve an image fallback with reduced-motion support; the opening must remain usable when autoplay is unavailable.
- Keep pack and bundle quantities in a shared tested module so customer guidance stays consistent.
- Preserve former texture and curl-comparison URLs as redirects to Shop and the mission page so existing links remain usable.
- Use the Node test API for shared quantity tests so they run under Bun without requiring Bun-only application types.
